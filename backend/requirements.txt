# Backend dependencies. Render installs these during its build step.

# resolved locally, so upper bounds are set only where a major version bump

# Async HTTP client for Pl@ntNet, Gemini and iNaturalist.

# Supabase over HTTPS/PostgREST, which avoids Render free tier's lack of
